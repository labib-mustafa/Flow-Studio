# Flow Studio - Project Summary

## Overview
Flow Studio is a comprehensive project management and creative collaboration web application designed primarily for designers, agencies, and creative teams. It provides a centralized hub to manage project tasks, store and organize files, write rich-text notes, and ideate using a full-featured infinite-canvas moodboard. The application features a modern, clean, and highly interactive user interface.

## What Kind of App is This?
Flow Studio is a **Creative Workflow Workspace** (SPA - Single Page Application). It merges traditional project management features (like task tracking and file asset management) with creative tools (like visual moodboards and rich-text note taking). Its target audience includes UI/UX designers, brand designers, marketing teams, and creative directors who need to keep inspiration and execution in the same context.

## Tech Stack
-   **Frontend Framework:** React 18
-   **Language:** TypeScript
-   **Build Tool:** Vite
-   **Styling:** Tailwind CSS (utility-first CSS)
-   **Icons:** Lucide React & Google Material Symbols
-   **Animations:** Framer Motion (`motion/react`)
-   **Canvas/Interaction Libraries:** 
    -   `react-moveable`: Used for drag, drop, resize, and rotation operations on the moodboard items.
    -   `react-selecto`: Used for creating selection marquees (drag to select multiple items) on the moodboard.

## App Architecture & Routing
The app currently operates as a client-side Single Page Application without a dedicated backend or router like `react-router`. Instead, it uses state-based view switching within `App.tsx` to handle navigation across the dashboard, projects summary, and granular project detail views. State management is largely handled using React hooks (`useState`, `useMemo`, `useEffect`) and Context (`SettingsContext`). A comprehensive, line-by-line static representation of all file pathways, imports/exports, and state triggers is cataloged in the core **`codebase_dependency_map.md`** file.

## Application Mechanisms (How It Works)
1.  **State-driven Views with Persistent Navigation Memory:** `src/App.tsx` maintains the `currentView` string state (e.g., `'projects'`, `'clients'`, `'project-moodboard'`). When the user clicks the Sidebar, this state updates, and the `renderContent` function returns the correct top-level component. It features an automated viewport memory state loop that persists and recovers the active workspace view tab within local storage (`last_viewed_page`) across browser refreshes seamlessly.
2.  **Persistent Zustand State Stores:** Separate stores (`moodboardStore.ts`, `projectStore.ts`, `taskStore.ts`, and `clientStore.ts`) manage modular operational slices securely. State is preserved across page sessions using local storage adapter middlewares automatically.
3.  **Moodboard Rendering Engine:** The moodboard does not use standard HTML5 `<canvas>`, but rather absolutely positioned DOM nodes synchronized with a `pan` and `zoom` state. `react-moveable` attaches transformation matrices to these DOM nodes on drag, while `react-selecto` listens for pointer events to find intersections between the drag bounds and the item bounds.
3.  **Global System Components:** Components like `DropdownMenu`, `CustomSelect`, and various Modals (residing in `/GlobalComponents/`) are highly reusable, headless-inspired UI blocks used across different pages to ensure a consistent look and feel based on the design system.
 
## Design Philosophy
Flow Studio follows a remarkably clean, minimal, and premium UI methodology. It utilizes extensive whitespace, subtle overlapping shadows (ring shadows instead of hard borders), and soft rounding (large border-radius scales). Interaction feedback is instant, using lightweight scaling animations and color transitions on hover/focus states to deliver a highly polished user experience.
 
-   **Refined Scrollbar System:** Custom-styled scrollbars across all scrollable containers (both vertical and horizontal) are set to an elegant, ultra-thin 5px. This resolves the thick native styling of browsers, utilizing soft slate colors (`#cbd5e1`) and rounded tracks that respond smoothly with hover interactions (`#94a3b8`), seamlessly integrating with the minimalist Cal.com-inspired design language.
-   **Crisp Modal system:** To enforce perfect high-contrast visual clarity and premium minimalism, all modals across the clients page and workspaces feature solid or rich dark overlay backdrops (`bg-slate-950/60` and `bg-black/60`) without any disruptive background blur filters. Furthermore, these overlays are bound and centered precisely within their relative parent content structures (rather than using viewport-fixed overlays), completely preserving the layouts of global components like the main sidebar.
